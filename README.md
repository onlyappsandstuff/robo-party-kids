# robo-party-kids

Kinderspiel: Viele Saugroboter fahren gleichzeitig durchs Zimmer (2D, Ansicht von oben), saugen Dreck, laden an Absaugstationen und leeren ihren Staubbehälter am Papierkorb.

- Läuft im Browser, auch auf Fire-Tablets (Silk). Einfach `index.html` öffnen.
- Zufälliger Raum bei jedem Start und bei „Neu".
- Bedienung: Roboter in den Raum ziehen oder antippen, Start drücken. Roboter mit leerem Akku oder vollem Behälter antippen oder zur Station bzw. zum Papierkorb ziehen.
